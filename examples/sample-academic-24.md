# 城市路网预测的现实约束
副标题：多源数据让短时预测更接近真实运行状态
类型：background

城市交通状态同时受到路网结构、出行需求、天气事件和突发拥堵影响。单一传感源通常只覆盖局部状态，难以稳定捕捉高峰期的快速波动。

指标：37%｜高峰误差上升
指标：5min｜预测时间粒度

# 关键科学问题
副标题：预测精度、可信度与可解释性需要同步解决
类型：logic-chart

研究目标不是单纯降低误差，而是构建能够支撑调度决策的可信预测系统。

- 跨模态特征如何对齐
- 图结构依赖如何编码
- 异常拥堵如何被识别
- 预测置信度如何表达
- 模型轻量化如何部署
- 决策反馈如何闭环

---

# 相关工作对比
副标题：从统计模型到深度时空图网络
类型：compare

本文方案在时空建模、模态融合和不确定性估计之间做平衡。

- ARIMA / SVR：解释性较好但难以捕捉非线性
- LSTM / TCN：能处理序列但缺少路网拓扑
- STGCN / DCRNN：图结构能力强但依赖单源数据
- Ours：多模态门控 + 区间预测 + 异常约束

# 消融实验
副标题：验证图结构、模态融合与置信约束的贡献
类型：compare

消融结果表明，去除任一关键模块都会造成指标回落，其中模态门控对异常场景最敏感。

- 完整模型：MAE 4.12
- 去除图结构：MAE 4.86
- 去除模态门控：MAE 5.03
- 去除区间约束：覆盖率下降 11.4%
